# Global World Journal (GWJ) Implementation Plan

> **Historical (build plan of 2026-06-23).** Kept as the record of the original v1 intent; it is NOT the current architecture. It predates the PostgreSQL port (MongoDB/Mongoose below are gone), the OIDC/SSM secret model and the CI-gated, digest-pinned deploys. Current sources of truth: `AGENTS.md`, `docs/DATABASE.md`, `docs/INFRA.md`, `infra/`.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a WSJ-style news site for "Global World Journal" — public reader SPA + admin CMS + remote MCP server for AI agents — Vite/Tailwind frontend, Express/MongoDB/Zod backend, deployed AWS + Cloudflare Pages.

**Architecture:** Bun monorepo (`packages/*`). `shared-types` holds Zod schemas consumed by all packages. `backend` is the single source of business logic (REST + service layer + Mongo + S3). `mcp` wraps the backend HTTP API as MCP tools. `frontend` is a Vite React SPA with a Cloudflare `_worker.js` for SEO. All three runtime packages depend only on `shared-types` + the HTTP contract, so they build in parallel.

**Tech Stack:** TypeScript (strict), Vite 6, React 19, Tailwind 4, Express 5, Mongoose 8, Zod, `@modelcontextprotocol/sdk`, bcrypt, jsonwebtoken, multer, `@aws-sdk/client-s3`, Vitest, supertest.

## Global Constraints
- Package manager: **bun** only (`bunx`, `bun install`, `bun.lock`). Never npm/yarn.
- `linker = "hoisted"` in root `bunfig.toml`.
- TypeScript strict. BANNED: `as any`, `@ts-ignore`/`@ts-expect-error`, `!` non-null assertions, silent `catch {}`, `console.log` in committed code, `var`, hardcoded secrets/URLs/magic numbers, TODO/FIXME/HACK comments, re-export barrels.
- Secrets via env only; never commit values. Guard placeholder `-`/empty before use.
- Categories (fixed enum, exact): `World, Business, Markets, Tech, Politics, Opinion, Arts`.
- Brand: name "Global World Journal"; accent red `#b31217`; fonts Playfair Display (headlines), Libre Franklin (labels), PT Serif (body).
- Display/byline names render directly from API fields; no frontend recomputation.
- Frequent commits, conventional-commit style, end body with the Claude co-author trailer.

```ts
import { z } from 'zod'
import { CategorySchema } from './category'
export const ContentBlockSchema = z.discriminatedUnion('type', [
  z.object({ type: z.literal('paragraph'), text: z.string().min(1) }),
  z.object({ type: z.literal('heading'), text: z.string().min(1) }),
  z.object({ type: z.literal('image'), url: z.string().url(), caption: z.string().optional(), credit: z.string().optional(), alt: z.string().default('') }),
  z.object({ type: z.literal('quote'), text: z.string().min(1), attribution: z.string().optional() }),
  z.object({ type: z.literal('list'), ordered: z.boolean().default(false), items: z.array(z.string().min(1)).min(1) }),
])
export type ContentBlock = z.infer<typeof ContentBlockSchema>
export const ArticleStatusSchema = z.enum(['draft','published'])
const HeroImageSchema = z.object({ url:z.string().url(), caption:z.string().optional(), credit:z.string().optional(), alt:z.string().default('') })
const SeoSchema = z.object({ metaTitle:z.string().optional(), metaDescription:z.string().optional(), ogImage:z.string().url().optional() }).default({})
export const ArticleInputSchema = z.object({
  title: z.string().min(1), deck: z.string().optional(), kicker: z.string().optional(),
  category: CategorySchema, author: z.string().min(1),
  body: z.array(ContentBlockSchema).default([]),
  heroImage: HeroImageSchema.optional(),
  status: ArticleStatusSchema.default('draft'),
  featured: z.number().int().min(0).default(0),
  tags: z.array(z.string()).default([]),
  seo: SeoSchema,
})
export type ArticleInput = z.infer<typeof ArticleInputSchema>
export const ArticleUpdateSchema = ArticleInputSchema.partial()
export const ArticleSchema = ArticleInputSchema.extend({
  id: z.string(), slug: z.string(), publishedAt: z.string().datetime().nullable(),
  createdAt: z.string().datetime(), updatedAt: z.string().datetime(),
})
export type Article = z.infer<typeof ArticleSchema>
export function slugify(title: string): string {
  return title.toLowerCase().normalize('NFKD').replace(/[̀-ͯ]/g,'')
    .replace(/[^a-z0-9\s-]/g,'').trim().replace(/\s+/g,'-').replace(/-+/g,'-')
}
```
`dto.ts`: `LoginInputSchema = z.object({username:z.string(),password:z.string()})`; `ArticleListQuerySchema = z.object({category:CategorySchema.optional(), featured:z.coerce.boolean().optional(), page:z.coerce.number().min(1).default(1), limit:z.coerce.number().min(1).max(50).default(20), status:ArticleStatusSchema.optional()})`. `index.ts` re-exports from the 4 modules (this is the package's own public surface, allowed).
